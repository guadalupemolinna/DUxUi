Instructivo: Cómo maquetar una página web básica

Pasos a seguir

  1. Definir la estructura del documento con la etiqueta doctype y la etiqueta html.
  2. Agregar la cabecera head con la codificación de caracteres, título y hojas de estilo.
  3. Redactar el contenido visible dentro de la etiqueta body usando marcado semántico.
  4. Aplicar reglas de CSS para dar estilo, color y tipografía a los elementos.
  5. Validar el código en navegadores y subir los cambios a un repositorio remoto en GitHub.

Recursos de documentación útiles

  • Aprende más sobre las etiquetas en la Guía de HTML en MDN.
  • Consulta las propiedades de estilo en la Guía de CSS en MDN.
